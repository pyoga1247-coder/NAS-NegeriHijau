PLC Modbus IoT Gateway

Elektronik & IoT
Rp5.887.000

PLC Modbus IoT Gateway adalah perangkat gateway industri yang berfungsi untuk menghubungkan berbagai PLC dengan sistem cloud dan platform IoT. Perangkat ini mampu mengumpulkan data dari berbagai PLC populer seperti Siemens, Mitsubishi, Omron, Delta, Allen-Bradley, dan Schneider, kemudian mengonversinya ke berbagai protokol komunikasi seperti Modbus TCP, MQTT, OPC UA, serta platform cloud seperti AWS, Alibaba Cloud, Huawei Cloud, dan ThingsBoard.

Dibangun dengan sistem operasi Linux embedded yang stabil, gateway ini dilengkapi dengan berbagai antarmuka seperti RS485/RS232, Ethernet RJ45, USB, slot SIM 4G, dan slot SD Card. Dengan dukungan Ethernet dan jaringan seluler 4G, perangkat ini memungkinkan monitoring dan pengumpulan data industri secara real-time, aman, dan jarak jauh. Cocok digunakan untuk sistem otomasi industri, SCADA, monitoring mesin, dan integrasi IoT industri.

ESP32 ESP-WROOM-32 Development Board 30 Pin Type-C WiFi Bluetooth IoT Module

Elektronik & IoT
Rp86.000

ESP32 ESP-WROOM-32 Development Board Type-C adalah papan mikrokontroler berbasis ESP32 yang dilengkapi dengan konektivitas WiFi dan Bluetooth dalam satu modul. Board ini dirancang untuk berbagai proyek Internet of Things (IoT) seperti sistem monitoring, otomasi, smart device, dan pengembangan teknologi berbasis jaringan.

Dengan prosesor ESP32-D0WD-V3, modul ini menawarkan performa yang cepat, konsumsi daya yang efisien, serta mendukung berbagai antarmuka seperti GPIO, ADC, DAC, PWM, I2C, I2S, dan UART. Dilengkapi dengan port USB Type-C dan chip CP2102 USB to UART, board ini memudahkan proses pemrograman dan debugging melalui komputer. Cocok digunakan untuk pengembangan proyek smart farming, sensor monitoring, automation system, dan aplikasi IoT lainnya.
